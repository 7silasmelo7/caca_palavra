# 🧩 Jogo de Caça-Palavras

Um jogo simples e divertido de **caça-palavras**, desenvolvido para treinar lógica, programação e proporcionar entretenimento.  
O objetivo é encontrar todas as palavras escondidas na matriz de letras.

---

## 🚀 Funcionalidades
- Geração automática de tabuleiros com palavras escondidas
- Contagem de tempo para desafiar seus amigos
